# Лабораторная №1. Основы 3D-графики

Вариант 2 — правильный октаэдр.

Программа отображает два октаэдра. Через ImGui можно переключать перспективную и ортографическую проекции, менять положение, поворот, масштаб и цвет объектов. Цвета вершин вычисляются из локальных координат и умножаются на выбранный цвет объекта. Для объектов используются отдельные uniform-буферы и наборы дескрипторов.

`Play object animation` включает движение по пространственной восьмёрке и вращение. Снятие галочки ставит анимацию на паузу, `Reset animation` сбрасывает фазу. В интерфейсе задаются скорость, радиус и высота траектории, скорость вращения. Параметры второго объекта находятся в разделе `Second octahedron`.

## Сборка

Нужны компилятор C++20, CMake 3.20+ и Vulkan SDK с `glslc`. Зависимости скачиваются при первой сборке.

На macOS подключить SDK:

```sh
source "$HOME/VulkanSDK/1.4.321.0/setup-env.sh"
```

Выполнить из папки лабораторной:

```sh
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug --parallel
./build-debug/cg-lab1
```

На Windows при сборке Visual Studio программа находится в `build-debug/Debug/cg-lab1.exe`.
