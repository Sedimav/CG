# Лабораторная №3. Текстурирование

Вариант 2 — правильный октаэдр. Основа — решение второй лабораторной на Vulkan, GLFW и ImGui.

У каждого из двух октаэдров выбирается материал: керамическая плитка, электронная плата или камень. PNG-файлы из `textures` декодируются библиотекой stb_image и загружаются в изображения Vulkan через staging-буферы. Текстура альбедо заменяет цвет вершин; освещение Блинна–Фонга сохранено.

## Управление

В разделе `Textures`:

- `First material` и `Second material` — независимый выбор материала.
- `First sampling effect` и `Second sampling effect` — анимированное искажение координат, смешивание нескольких выборок одной текстуры и изменение цвета. По умолчанию эффект включён у второго объекта.
- `Animate sampling`, `Sampling speed`, `Effect strength` — пауза, скорость и сила эффекта.
- `UV scale` — количество повторений текстуры.
- `Specular map` и `Emissive map` — использование карт блеска и свечения.

Керамика содержит карту блеска. Электронная плата — карты блеска и свечения. Для отсутствующих карт используется чёрная текстура 1×1: например, камень не даёт ни бликов, ни собственного свечения. Все PNG подготовлены процедурно; карта свечения использует градиентный шум. Приложение читает готовые файлы, а не генерирует текстуры при запуске.

Чтобы проверить свечение, выбрать `Circuit`, обнулить `Ambient light` и `Directional intensity`, удалить точечные источники и прожекторы. Светящиеся участки останутся видимыми. Они не освещают соседние объекты. Для сравнения карт блеска отключить эффект сэмплирования и двигать камеру или источник. В разделе `Lighting` сохранены настройки источников из ЛР2.

## Данные и память

Вершина содержит позицию, нормаль и UV. На границах UV-развёртки вершины продублированы, сглаженные нормали сохранены. Вершинные и индексные данные копируются командами GPU из staging-буферов в буферы с памятью `DEVICE_LOCAL`. На компьютерах с общей памятью CPU/GPU это не означает отдельную физическую микросхему VRAM.

Set 0 содержит UBO сцены и два SSBO источников. Для каждого материала есть set 1: один и тот же динамический UBO моделей и три пары изображение-сэмплер. Смещение модели выбирается в `vkCmdBindDescriptorSets` с учётом `minUniformBufferOffsetAlignment`.

16 байт push-констант содержат флаги карт и эффекта, время, силу эффекта и масштаб UV. Матрицы и материал остаются в UBO. Альбедо и свечение читаются как sRGB, карта блеска — как линейные данные. Сэмплер использует линейную фильтрацию и повторение; у текстур один mip-уровень.

## Сборка и запуск

Нужны C++20, CMake 3.20+ и Vulkan SDK с `glslc`. Первая сборка скачивает зависимости.

На macOS подключить SDK:

```sh
source "$HOME/VulkanSDK/1.4.321.0/setup-env.sh"
```

Из папки лабораторной:

```sh
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug --parallel
./build-debug/cg-lab3
```

На Windows с Visual Studio: `build-debug/Debug/cg-lab3.exe`.

CMake копирует PNG и компилирует GLSL в папку сборки. При изменении текстур или шейдеров нужно повторить сборку. Отдельный скрипт запуска не требуется.
