# Лабораторная №2. Камера и освещение

Вариант 2 — правильный октаэдр.

В сцене реализованы камера и освещение по модели Блинна–Фонга. Через ImGui меняются положение, поворот и угол обзора камеры, альбедо, цвет блика и его показатель степени, ambient и направленный свет.

В разделах `Point lights` и `Spot lights` можно добавлять, удалять и настраивать источники. Для неподвижного света отключить `Animate lights`. Для демонстрации только направленного света удалить остальные источники.

Точечные и прожекторные источники используют затухание по закону обратных квадратов с ограничением минимального расстояния 0.1. Внутренний и внешний углы задают мягкую границу прожектора. `Show light visualization` включает цветные маркеры и контуры конусов.

Данные сцены находятся в set 0, данные модели — в set 1. Массивы света передаются через storage-буферы `std430` без фиксированной длины в GLSL. Приложение поддерживает по 8 источников каждого типа.

## Сборка

Нужны компилятор C++20, CMake 3.20+ и Vulkan SDK с `glslc`. Зависимости скачиваются при первой сборке.

На macOS подключить SDK:

```sh
source "$HOME/VulkanSDK/1.4.321.0/setup-env.sh"
```

Выполнить из папки лабораторной:

```sh
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug --parallel
./build-debug/cg-lab2
```

На Windows при сборке Visual Studio программа находится в `build-debug/Debug/cg-lab2.exe`.
